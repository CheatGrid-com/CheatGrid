# Requests 📨

Can't find what you need? Ask for it. Tell us what you're after and we'll look into it, research it properly, and build it in the same format as everything else on CheatGrid. Got an idea for the site itself? Send that too.

## What you can request

- 📋 **A cheat sheet** on a tool, language, framework or concept we don't cover yet.
- 🎓 **A certification**: a cheat sheet plus practice tests, mapped to the exam's objectives.
- 🃏 **A flashcard deck** for a topic that doesn't have one yet.
- 📝 **A practice test** for a topic that doesn't have one yet.
- 🍳 **A cookbook recipe**: a short, step-by-step fix for a real problem you keep running into.
- 🌱 **A Life Skills page** on an everyday topic.
- ✅ **A checklist** for a task your role meets: say what you're doing and which roadmap it belongs to.
- 🗺️ **A roadmap** for a role or a goal.
- 💬 **Something else**: a feature idea, a change you'd like, or anything that doesn't fit the boxes above.

## How to send one

1. Open **[Request](https://www.cheatgrid.com/request)**. You'll also find it in the menu under the top bar, in search when nothing matches, on the Certifications page, and under an assistant answer when our library has nothing on your question.
2. Pick what kind of thing you want (or **Other** for an idea) and type it in a few words.
3. As you type, we show what we already have. If it's already on CheatGrid, you'll get the link instead, so you can start reading straight away.
4. Add a line on **what it should cover**, and any **details** that matter to you: specific features, the exam code, your level, the parts you find hardest.
5. Send it. You need to be signed in, so we know who to tell when it's ready.

## What happens next

- We read every request. The ones more people ask for tend to go first.
- If it fits CheatGrid, we build it. We can't promise a date, and some requests won't make it (too narrow, or not a good fit for the format).
- When it's live, **we email you the link**. You can also check on the Request page, under **Your requests**.
- If we decide not to build it, we'll tell you why. The reason shows under **Your requests**, and we'll usually email it to you too.

## What it costs

Requesting is free. What we build joins the library like everything else:

- a requested **cheat sheet**, **flashcard deck**, **practice test**, **recipe**, **Life Skills page** or **checklist** is part of **Pro**
- a requested **certification** (cheat sheet and practice tests) is part of **Pro+**
- a requested **roadmap** is free to follow, like every roadmap (the cheat sheets inside keep their own plans)

## A few limits

- You can send **3 requests a day**.
- You can't ask for the same thing twice while it's still open. (A cheat sheet and a practice test on the same topic are two different requests, so that's fine.)
- Things we already have can't be requested. Search for them instead with **[Search](assistant-and-search.md)**.
